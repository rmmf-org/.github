# rmmf-org/.github

Organization-wide GitHub settings for the Rouben Malian Memorial Foundation.

- `profile/README.md` is shown on the organization's page at https://github.com/rmmf-org. Edit it to change that page.
- This repository must stay **public** for GitHub to show the profile README.
- `.github/ISSUE_TEMPLATE/` holds the default issue forms for every repository in the organization that has no forms of its own: Bug, Feature, Task, Epic and Initiative. Each form sets the matching organization issue type (Initiative > Epic > Feature / Task / Bug).
- `.github/pull_request_template.md` is the default pull request template. Link the issue with "Closes #n".
